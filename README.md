This is a lightweight quiz app for the Greek Ham radio exam (εξετάσεις ραδιοερασιτεχνών) that runs locally in your browser. It is based on the official exam questionnaire. There are multiple modes such as practice mode, exam simulation mode and serial practice with progress saving. 
Download and extract the compressed file first. Then you just run the index file on the test folder of your choice (either Category 1/SV OR the entry-level SY). 
If there is any issue let me know.

Mια ελαφριά εφαρμογή κουίζ για τις εξετάσεις ραδιοερασιτεχνών, η οποία εκτελείται τοπικά στον περιηγητή (browser) σας. Βασίζεται στο επίσημο ερωτηματολόγιο των εξετάσεων. Διαθέτει διάφορες λειτουργίες, όπως λειτουργία εξάσκησης, προσομοίωση εξετάσεων και διαδοχική εξάσκηση με δυνατότητα αποθήκευσης της προόδου. Αρχικά, κατεβάστε και αποσυμπιέστε το συμπιεσμένο αρχείο. Στη συνέχεια, απλώς ανοίξτε το αρχείο «index» που βρίσκεται στον φάκελο της κατηγορίας που σας ενδιαφέρει (είτε Κατηγορία 1/SV είτε η εισαγωγική κατηγορία SY). Αν αντιμετωπίσετε οποιοδήποτε πρόβλημα, ενημερώστε με.
